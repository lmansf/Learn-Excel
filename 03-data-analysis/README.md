# Level 3 · Data Analysis

**Level:** Intermediate

Structure, validate, clean, summarize, and visualize data — Tables, PivotTables, charts, and what-if models.

| # | Lesson | Time | Objectives |
|:-:|---|:-:|---|
| 3.1 | [Excel Tables, Structured References & Named Ranges](01-tables-named-ranges/README.md) | 50 min | • Convert ranges to Excel Tables and name them<br>• Write structured references like tblInventory[UnitCost] and [@QtyOnHand]<br>• Use calculated columns, the Total Row, and slicers on Tables<br>• Create, manage, and use named ranges and named constants |
| 3.2 | [Data Validation & Conditional Formatting](02-data-validation-conditional-formatting/README.md) | 55 min | • Restrict entries with list, number, date, length, and custom-formula validation<br>• Build dependent drop-down lists<br>• Highlight what matters with conditional formatting rules, data bars, color scales, and icon sets<br>• Write formula-based rules that format entire rows |
| 3.3 | [Cleaning Messy Data](03-data-cleaning/README.md) | 60 min | • Spot common data problems: stray spaces, inconsistent case and categories, text dates, duplicates<br>• Fix them with TRIM, PROPER, SUBSTITUTE, VALUE, DATEVALUE, and lookup mapping tables<br>• Use Text to Columns, Flash Fill, Remove Duplicates, and Go To Special<br>• Document a repeatable cleaning process |
| 3.4 | [PivotTables](04-pivottables/README.md) | 60 min | • Build PivotTables from a Table and arrange rows, columns, values, and filters<br>• Change summaries (Sum, Count, Average) and Show Values As (% of total, difference, running total)<br>• Group dates and numbers; filter with slicers and timelines<br>• Add calculated fields and use GETPIVOTDATA |
| 3.5 | [Charts & Data Visualization](05-charts-visualization/README.md) | 55 min | • Choose the right chart for comparisons, trends, parts of a whole, distributions, and relationships<br>• Build and format column, line, bar, scatter, histogram, combo, and Pareto charts<br>• Add trendlines, dynamic titles, and sparklines<br>• Design clear, accessible charts that tell one story |
| 3.6 | [What-If Analysis: Goal Seek, Scenarios, Data Tables & Solver](06-what-if-analysis/README.md) | 60 min | • Structure a model with separate inputs, calculations, and outputs<br>• Find break-even points with Goal Seek<br>• Compare cases with Scenario Manager and sensitivity Data Tables<br>• Optimize a staffing mix with Solver |
