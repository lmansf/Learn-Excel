# Level 5 · Automation with Macros & VBA

**Level:** Expert

Record macros, then write VBA: variables, loops, ranges, custom functions, error handling, events, and UserForms.

| # | Lesson | Time | Objectives |
|:-:|---|:-:|---|
| 5.1 | [Recording Your First Macros](01-recording-macros/README.md) | 45 min | • Show the Developer tab and set macro security safely<br>• Record, run, and save macros in a macro-enabled workbook (.xlsm)<br>• Choose between absolute and relative recording<br>• Run macros from buttons, shortcuts, and the Quick Access Toolbar — and read the recorded code |
| 5.2 | [VBA Fundamentals](02-vba-fundamentals/README.md) | 60 min | • Navigate the Visual Basic Editor and organize code in modules<br>• Declare variables with the right data types and Option Explicit<br>• Control flow with If, Select Case, For, For Each, and Do loops<br>• Debug with breakpoints, stepping, the Immediate window, and Debug.Print |
| 5.3 | [VBA: Ranges, Worksheets & Workbooks](03-vba-ranges-worksheets/README.md) | 65 min | • Navigate the object model: Application, Workbooks, Worksheets, Range<br>• Find the last row and work with CurrentRegion, Offset, and Resize<br>• Loop through sheets; add, copy, rename, and delete them<br>• Process data fast with arrays, AutoFilter, and Sort — without Select |
| 5.4 | [VBA: Custom Functions, Dictionaries & Error Handling](04-vba-functions-error-handling/README.md) | 65 min | • Write user-defined functions (UDFs) you can call from cells<br>• Pass arguments ByVal/ByRef, use Optional arguments, and return errors with CVErr<br>• Count and group with Collections and Scripting.Dictionary<br>• Handle errors gracefully with On Error, the Err object, and cleanup code |
| 5.5 | [Events, UserForms & Automated Reports](05-events-userforms-automation/README.md) | 75 min | • Respond to workbook and worksheet events (Open, Change, BeforeSave)<br>• Build a validated data-entry UserForm that writes to a Table<br>• Automate a report: combine files with Dir, export to PDF, save timestamped copies<br>• Know the safe limits of automation and when to use Office Scripts or Power Automate |
