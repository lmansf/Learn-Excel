# Level 1 · Foundations

**Level:** Beginner

Find your way around Excel, enter and format data, write your first formulas, and sort and filter a real dataset.

| # | Lesson | Time | Objectives |
|:-:|---|:-:|---|
| 1.1 | [The Excel Interface & Navigation](01-excel-interface-navigation/README.md) | 30 min | • Name the parts of the Excel window: ribbon, Quick Access Toolbar, Name Box, formula bar, grid, sheet tabs, status bar<br>• Understand workbooks, worksheets, cells, ranges, and cell addresses<br>• Move around large datasets fast with keyboard shortcuts and Go To<br>• Read quick statistics from the status bar<br>• Freeze panes, zoom, and hide/unhide rows, columns, and sheets |
| 1.2 | [Data Entry, AutoFill & Editing](02-data-entry-autofill/README.md) | 40 min | • Recognize how Excel stores text, numbers, dates, times, and TRUE/FALSE<br>• Enter and edit data efficiently (F2, Ctrl+Enter, Ctrl+D, Alt+Enter)<br>• Create series with AutoFill, the Fill Series dialog, and Flash Fill<br>• Use Copy, Paste Special (values, transpose, formats), and Find & Replace<br>• Avoid classic traps: lost leading zeros, numbers stored as text, accidental dates |
| 1.3 | [Formatting Cells & Number Formats](03-formatting-cells/README.md) | 45 min | • Apply number formats: Number, Currency vs Accounting, Percentage, Date, Time, Text<br>• Write custom number formats (leading zeros, units, colors, thousands)<br>• Format fonts, fills, borders, alignment, and wrap text — and avoid merged cells<br>• Use Format Painter, cell styles, and themes for consistent reports<br>• Understand that formatting changes how a value looks, not the value itself |
| 1.4 | [Your First Formulas & Functions](04-basic-formulas/README.md) | 45 min | • Write formulas with operators and the correct order of operations<br>• Use SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, and COUNTBLANK<br>• Calculate rates and percentages such as bed occupancy<br>• Copy formulas down a column and read common errors (#DIV/0!, #NAME?, #VALUE!)<br>• Round results with ROUND |
| 1.5 | [Relative, Absolute & Mixed References](05-cell-references/README.md) | 45 min | • Predict how relative references change when a formula is copied<br>• Lock references with \$ (absolute) and use F4 to toggle<br>• Build two-way grids with mixed references (\$A1 and A\$1)<br>• Reference other sheets and sum the same cell across sheets (3-D references) |
| 1.6 | [Sorting & Filtering Data](06-sorting-filtering/README.md) | 45 min | • Sort by one or several columns, including custom orders<br>• Filter text, numbers, and dates with AutoFilter (and Top 10, by color)<br>• Summarize only visible rows with SUBTOTAL and AGGREGATE<br>• Use Advanced Filter for complex AND/OR criteria and unique lists |
