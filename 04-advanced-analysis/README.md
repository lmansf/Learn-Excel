# Level 4 · Advanced Analysis

**Level:** Advanced

Modern Excel: dynamic arrays, LET/LAMBDA, Power Query, the Data Model with DAX, statistics, and dashboards. Lesson 4.1 and parts of 4.2 need Microsoft 365 or Excel 2024, and Lesson 4.4 needs Excel for Windows.

| # | Lesson | Time | Objectives |
|:-:|---|:-:|---|
| 4.1 | [Dynamic Arrays: FILTER, SORT, UNIQUE & More](01-dynamic-arrays/README.md) | 125 min | • Understand spilling, the # spill reference, and #SPILL! errors<br>• Extract lists with UNIQUE, FILTER, SORT, and SORTBY<br>• Generate sequences with SEQUENCE and reshape with TAKE, DROP, CHOOSECOLS, VSTACK, and HSTACK<br>• Combine functions into one-formula reports |
| 4.2 | [Advanced Formulas: LET, LAMBDA & Array Logic](02-advanced-formulas-let-lambda/README.md) | 150 min | • Write multi-condition array logic with SUMPRODUCT and boolean math<br>• Make complex formulas readable and fast with LET<br>• Create reusable custom functions with LAMBDA and the Name Manager<br>• Use MAP, REDUCE, SCAN, BYROW, and audit formulas with Evaluate Formula |
| 4.3 | [Power Query: Import, Transform & Combine](03-power-query/README.md) | 170 min | • Import CSV files and whole folders with Get & Transform<br>• Clean and reshape data with Applied Steps: types, splits, filters, unpivot, group by<br>• Merge (join) and append queries<br>• Build refreshable, repeatable data pipelines and read the M code behind them |
| 4.4 | [Data Model, Power Pivot & DAX](04-power-pivot-dax/README.md) | 175 min | • Design a star schema and load tables into the Data Model<br>• Create relationships and a proper date table<br>• Write DAX measures with SUM, COUNTROWS, DISTINCTCOUNT, DIVIDE, and CALCULATE<br>• Use time intelligence (TOTALYTD, SAMEPERIODLASTYEAR) and iterators (SUMX, AVERAGEX) |
| 4.5 | [Statistics & Forecasting](05-statistics-forecasting/README.md) | 150 min | • Summarize distributions with the Analysis ToolPak and histograms<br>• Measure relationships with correlation and linear regression<br>• Test differences with t-tests and quantify uncertainty with confidence intervals<br>• Forecast volumes and monitor processes with control charts |
| 4.6 | [Building Interactive Dashboards](06-dashboards/README.md) | 160 min | • Plan a dashboard around audience, questions, and KPIs<br>• Build KPI cards and selector-driven formulas<br>• Connect slicers to multiple PivotTables and drive charts from selections<br>• Polish layout, interactivity, and performance |
